# Getting started (for Kaja)

## Every time Claude changes code
1. Open **GitHub Desktop** – the changes show up on the left.
2. Write a short summary (Claude suggests one), click **Commit to main**, then **Push origin**.

## Keys
Open `Secrets.env` in this folder (TextEdit is fine) and paste the Hardcover token after `HARDCOVER_TOKEN=`. Save. Done.

## Running the apps
- iPhone: open `ios/QuietReading.xcodeproj` in Xcode, choose a simulator or your iPhone Duo, press ▶︎.
- Android: open the `android` folder in Android Studio, wait for Gradle sync, choose an emulator, press ▶︎.
